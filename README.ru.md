Tor Radar — статическая дашборд-панель аналитики Tor-ретрансляторов и набор данных, полностью построенные на инфраструктуре GitHub Pages.

Проект собирает публичные метаданные Tor-ретрансляторов, хранит компактные исторические снимки и публикует интерактивную дашборд-панель, работающую в браузере, без необходимости в бэкенде, базе данных или внешних runtime-сервисах.

## Обзор

Tor Radar отслеживает инфраструктуру публичных Tor-ретрансляторов во времени и публикует нормализованные снимки, пригодные для операционной наблюдаемости, аналитики, конвейеров обогащения данных (enrichment pipelines) и лонгитюдного анализа сети.

Проект сосредоточен на:

* видимости реестра ретрансляторов
* отслеживании сетевых изменений (churn)
* анализе концентрации по ASN
* распределении по странам
* классификации ролей ретрансляторов
* хранении исторических трендов

Все выходные данные — статические артефакты, генерируемые посредством запланированных рабочих процессов GitHub Actions.

## Источники данных

| Источник                                 | Назначение                         |
| ---------------------------------------- | ---------------------------------- |
| `https://www.dan.me.uk/torlist/?full`    | Публичный список IP Tor-ретрансляторов |
| `https://onionoo.torproject.org/details` | Официальные метаданные Tor-ретрансляторов |

Сборщик объединяет список ретрансляторов с метаданными Onionoo для формирования обогащённых сетевых снимков.

## Развёртывание на GitHub Pages

Рабочий процесс GitHub Actions обновляет наборы данных ежечасно и разворачивает сгенерированную дашборд-панель непосредственно на GitHub Pages.

Рабочий процесс:

```text id="r3n8rb"
.github/workflows/tor-radar.yml
```

Поведение развёртывания:

* `public/` становится корнем Pages
* `data/` разворачивается вместе с ресурсами дашборда
* UI получает `data/current/network.json` напрямую из хранилища Pages

Необходимые настройки репозитория:

* Включить GitHub Pages
* Установить источником Pages значение `GitHub Actions`
* Предоставить Actions права на чтение/запись репозитория

## Политика хранения

Конфигурация хранения по умолчанию:

| Набор данных    | Срок хранения                 |
| --------------- | ----------------------------- |
| Файлы снимков   | Последние 168 часовых снимков |
| История сводок  | Последние 720 строк           |

Переопределения для workflow:

| Переменная                     | Описание                                                     |
| ------------------------------ | ------------------------------------------------------------ |
| `TOR_RADAR_SNAPSHOT_RETENTION` | Количество хранимых снимков                                  |
| `TOR_RADAR_HISTORY_RETENTION`  | Срок хранения истории сводок                                 |
| `TOR_RADAR_DAN_REFRESH_HOURS`  | Интервал обновления relay из внешнего источника (upstream)   |
| `TOR_RADAR_USER_AGENT`         | User-agent сборщика                                          |

---

## Примечания по эксплуатации

* Инвентаризация relay формируется на основе публичных данных из upstream-источников
* Сама по себе концентрация relay не должна трактоваться как атрибуция
* Совпадение инфраструктуры между провайдерами является ожидаемым
* Историческая ротация (churn) и метаданные relay предназначены для использования в качестве аналитических сигналов
* Проект намеренно избегает активного зондирования и взаимодействия с relay
